# Módulo: Empresas (CLI)

Cadastro de empresas, histórico de propostas e histórico de interações por empresa.

- `components/` — ClientList, ClientForm, ClientDetail, InteractionHistory
- `types.ts` — tipos de Empresa/Interação (definidos junto com o schema em DB-02/DB-04)

Depende de: `DB-02`, `DB-04`, `DB-06`, `AUTH-04`, `AUTH-05`, `PIPE-06`. Ver `docs/cronograma.md`.
